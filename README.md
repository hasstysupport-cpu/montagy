# مونتاجي — Montagy v3.0 🎬

**استوديو مونتاج فيديو كامل — قوة CapCut وبساطة InShot في تطبيق واحد.**

> مبني بعد تحليل معمّق بالهندسة العكسية لتطبيقي **CapCut** و **InShot**
> (الفلاتر الأصلية، مصطلحات الأدوات العربية، لوحات الألوان، وبنية محرك التحرير).

## ✨ المزايا

- **محرر متعدد التراكات**: فيديو + صور + نصوص + ملصقات + موسيقى + تعليق صوتي
- **شريط أدوات بنمط CapCut**: 15 أداة عند تحديد أي مقطع (تقسيم/سرعة/صوت/فلتر/ضبط/مؤثرات/تدوير/قص/عكس/تجميد/استخراج صوت/تكرار/استبدال/حذف)
- **42 فلتر LUT حقيقي** (.cube مدمج) بتصنيفات CapCut — يُطبَّق بالمعاينة الحية (مصفوفات مُناسَبة) وبـ lut3d في التصدير
- **لوحة ضبط 11 بارامتر**: سطوع/تباين/تشبع/حدة/إبرازات/ظلال/حرارة/تدرج/هوى/تلاشي/تظليل — فوري + خبز كامل
- **10 مؤثرات فيديو**: ضبابي، حبيبات، حلمي، توهج، نيون، بكسل، مرآة، اهتزاز... بسلاسل FFmpeg حقيقية
- **35 انتقال** xfade + إطارات مفتاحية للنص والملصقات + طبقات PiP
- **نصوص عربية فاخرة**: 15 خط (IBM Plex Sans Arabic، Alexandria، أميري، ريم كوفي، القاهرة، عارف رقعة...)
- **صوت**: موسيقى، تعليق صوتي، استخراج الصوت، تلاشي دخول/خروج
- **كانفس**: 9 نسب أبعاد + خلفيات (ألوان CapCut الأصلية / تمويه)
- **تصدير حقيقي 100%**: FFmpeg (x264) حتى 2K مع تقدم مباشر وحفظ في الاستوديو
- **ثيمات**: داكن (أزرق/أسود) وفاتح (ورقي/أبيض)

## 🔧 التقنيات

Flutter 3.27 (Skia) • ffmpeg_kit (full-gpl: x264 + fribidi + lut3d) • video_player • just_audio
