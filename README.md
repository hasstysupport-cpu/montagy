# مونتاجي — Montagy v2.0 🎬

**استوديو مونتاج فيديو كامل — قوة CapCut وبساطة InShot في تطبيق واحد.**

> مبني بعد تحليل معمّق بالهندسة العكسية لتطبيقي **CapCut** و **InShot**
> (الفلاتر الأصلية، مصطلحات الأدوات العربية، لوحات الألوان، وبنية محرك التحرير).

## ✨ المزايا

- **محرر متعدد التراكات**: فيديو + صور + نصوص + ملصقات + موسيقى + تعليق صوتي
- **أدوات التعديل**: تقسيم • تشذيب • سرعة (0.25x-4x) • عكس • تجميد الإطار • تدوير • قلب • اقتصاص تفاعلي • كتم
- **44 فلتر أصلي** بأسماء كتالوج InShot الحقيقي (سينما ١-٥، فيلم ١-٥، بشرة، طحلب، ...) + تعديل لوني كامل
- **نصوص عربية فاخرة**: 11 خط عربي (Alexandria, أميري، ريم كوفي، عارف رقعة، لاله زار...)
- **ملصقات**: إيموجي + صور من المعرض مع سحب وتكبير
- **صوت**: موسيقى، تعليق صوتي (تسجيل)، استخراج الصوت من الفيديو، تلاشي دخول/خروج
- **كانفس**: 9 نسب أبعاد + خلفيات (ألوان CapCut الأصلية / تمويه)
- **انتقالات**: تلاشي، انزلاق، مسح، دائرة، تذويب، تكبير... (9 انتقالات)
- **تصدير حقيقي 100%**: FFmpeg (x264) حتى 2K مع تقدم مباشر وحفظ في الاستوديو
- **ثيمات**: داكن (أزرق/أسود) وفاتح (ورقي/أبيض)

## 🔧 التقنيات

Flutter 3.27 • ffmpeg_kit (full-gpl: x264 + fribidi) • video_player • just_audio • record
